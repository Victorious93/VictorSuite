# VictorSuite plugins

This is the official plugin catalog for VictorSuite.

The machine-readable feed is [catalog.json](catalog.json). The app uses that file as the catalog; this page is the human-readable list.

## Official catalog

There are no installable plugins in the official catalog yet.

The current `catalog.json` includes only a schema example named "Example Hello". It is not a real plugin: it has no downloadable artifact (size 0, a placeholder checksum, and no signature). Do not try to install it.

When real plugins are published, they will be listed here with their name, version, licence, and source.

## In the app

Open **Install Module** from the side menu or the Files drawer. The download button on that screen opens this page.

The plugin system design is in [PLUGIN_SYSTEM.md](../PLUGIN_SYSTEM.md).
